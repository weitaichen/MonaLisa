## Implementation deviations (recorded 2026-10-08)

The task text below is kept as written; where the shipped code differs, it is marked **[→ Dn]** and explained here.

- **D1 · Delegate and person masks.** In tasks-vision 0.10.35, CPU delegate + `outputSegmentationMasks` aborts the wasm module on every detect (image_frame.cc `Check failed: 1 == ChannelSize()`), in IMAGE and VIDEO mode, full and lite; evidence: `tests/harness/b3/probe.mjs`. So masks run on the **GPU graph** with the synchronous `detect` + `close()` (masks read inside the callback come back empty), and when the GPU graph cannot be created the tracker falls back to **CPU without masks** (`BodyDetection.mask = null`). `resolveDelegate` in `src/tracking/bodyTracker.ts` implements this; never re-create the CPU + masks combination.
- **D2 · Services do not force a delegate.** `ensureBodyTracker` calls `createBodyTracker` without `delegate: 'CPU'`; the choice lives in `resolveDelegate` (D1).
- **D3 · Torso without a mask.** The torso sliders (瘦身 / 細腰 / 美臀) also work without a mask, from keypoint-ratio widths scaled by `NO_MASK_GAIN` (0.7, `src/body/field.ts`); only 腰臀比 strictly needs the mask (`paramAvailability`, `src/body/measure.ts`).
- **D4 · 增高 stretch is capped.** S = 1 + min(0.15·amount, 0.08 / (bottom − top)), so the content pushed off the bottom stays ≤ 8 % of the height (`heightBandStretch`, `src/body/bands.ts`; `HeightBand` in `src/types.ts`). The HeightBandOverlay must be given that same function (the Editor passes it); its own default is the uncapped 1 + 0.15·amount.

## Tasks (all parallel)

### B1 · body-geometry — owns `src/body/**` (+ `src/body/*.test.ts`)
`measureBody` / `paramAvailability` per BR §量測與閘控 (torso frame from 11/12/23/24; widths from the mask by scanlines, never keypoint distance; waist search 0.35–0.75 L above the hip midpoint excluding arm pixels; hip line; limb half-widths as the median of 3–5 normal samples; gating: visibility > 0.6, in frame with margin, L > 15 % of image height; legs need 23–28 and feet in frame; head needs a face; fall back to conservative keypoint-based widths only when the mask is null **[→ D3]**). Reasons in 繁體中文. `buildBodyField` per BR §管線/§參數: RG field ≈256 long edge matching the aspect; capsule fields `v_src = v·(1 + k·a(t)·φ(r))`, φ=(1−r²)², R=ρW, per-capsule `k·a ≤ 0.8` and summed bound < 1.25; `legBand` (C¹, monotonic) for 長腿 with S clamped so the feet stay in frame; manual 增高 band (stretch 1 + 0.15·amount inside the band **[→ D4: capped]**; frame size unchanged, the content below shifts down, crop of the bottom edge ≤ 8 % of the height); 腰臀比 by inverting measured W_w / W_h (70 % waist in, 30 % hip out); 美臀 bidirectional; 直角肩 anisotropic upward shift; 小頭 scaleAround on the face; 天鵝頸 vertical-only head lift with smoothstep fade to the shoulder line; 背景保護 multiplies the field by the dilated + feathered person mask (band ≥ 4Δ); part exclusion (arms vs torso) by `(1 − w_other)`; `bodyActive`; `fieldMinJacobian`. Tests: max settings never fold (min det J > 0.3), zero field outside the feathered mask with protect on, neutral → null, band-only works with `measure = null`, waist max shrinks the measured mask waist ≈ 10–15 %, gating reasons. Use `tests/fixtures/pose_fullbody.json` (B3) when present, else synthetic poses.

### B2 · engine — owns `src/engine/passes/reshape.ts`, `src/engine/pipeline.ts`, `src/engine/index.ts`, `src/engine/uniforms.ts`, engine tests (`src/engine/*.test.ts` except params), `tests/harness/b2/**`

Yaw attenuation stays face-only. Both `render` and `renderToImageData` apply the field (preview = export). Prove in headless Chromium: zero field = bit-exact identity; a constant field shifts by exactly that many UV; body + face together; no GL errors; context-loss restore re-uploads.
